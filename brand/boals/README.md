# boals — brand direction

A modern, playful identity for the AI coding workspace. The central idea is **two conversational dots becoming one friendly companion**: a compact connected silhouette with two small eyes, paired with a rounded lowercase wordmark.

- Personality: curious, friendly, precise, quietly clever.
- Tagline: **Good company. Great code.**
- Palette: Ink `#151515`, Paper `#F3F1EA`, Pebble `#8E918B`, Blue `#8AA7ED`.
- Proposed typography: Inter for product UI, Geist Mono for code and technical details.
- Inspiration: the approachability and minimal expression of Grok bot and ChatGPT dots, expressed through an original mark.

The overview board is a raster brand concept, generated with the built-in image generation tool. It presents logo, construction, UI, palette, typography, physical application, image direction, and expressive states in a 3 × 3 grid. Production vector assets and exact typography should be finalized before applying this identity to the app.

The app is unchanged by this brand exploration. The generation prompt is saved beside the board in `generation-prompt.txt`.
